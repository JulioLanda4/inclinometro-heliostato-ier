# Datos de calibración

Incorporar aquí series de aceleraciones brutas y corregidas, fecha de calibración, temperatura (si se dispone), identificador de unidad y parámetros calculados.

**No se agregan archivos de datos ficticios.** Las observaciones exploratorias discutidas durante el desarrollo están resumidas en `documentacion/calibracion.md`, sin presentarlas como conjunto completo de datos.
